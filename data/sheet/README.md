# 운영자 입력 시트

구글 시트의 두 탭을 CSV로 내려받아 이 폴더에 두거나, GitHub Actions가 매일 자동으로 받아옵니다
(`SHEET_NOTICES_CSV_URL`, `SHEET_COMMENTARY_CSV_URL` 비밀값에 시트의 "웹에 게시 → CSV" 주소를 넣으면 됩니다).

파일은 UTF-8(BOM 있어도 됨)로 저장합니다. 엑셀로 열어 저장해도 됩니다.

## notices.csv — 공고 목록

| 열 | 필수 | 적는 법 |
|---|---|---|
| slug | 필수 | 주소용 식별자. 소문자 영문·숫자·하이픈만(예: `seoul-youth-rent-2026`). 한 번 정하면 바꾸지 않습니다. 같은 정책이 다음 해에 다시 열리면 같은 slug의 내용을 갱신합니다. |
| 제목 | 필수 | 정책·공고명 그대로 |
| 카테고리 | 필수 | `살 곳` / `지원받을 곳` / `즐길 곳` / `도전할 곳` (영문 housing/support/play/challenge도 됨) |
| 지역 | 필수 | `전국` 또는 시·도 이름(서울, 부산, 대구, 인천, 광주, 대전, 울산, 세종, 경기, 강원, 충북, 충남, 전북, 전남, 경북, 경남, 제주). `서울특별시`처럼 정식 명칭도 됩니다. 온라인만 진행되면 `전국`. |
| 세부지역 | 선택 | 시·군·구(예: 수원, 마포) |
| 대상 | 필수 | 나이·거주·소득 등 원문 기준 그대로 |
| 시작일 | 선택 | `2026-03-01` 형식 |
| 마감일 | 필수(날짜가 있으면) | `2026-03-31` 형식. 마감일이 지나면 자동으로 "마감" 처리됩니다. |
| 마감유형 | 마감일이 없을 때 | `상시` / `선착순` / `예산소진` / `미확인` |
| 상태 | 선택 | `마감`이라고 적으면 마감일과 상관없이 마감으로 표시합니다. |
| 혜택 | 필수 | 지원 내용. 금액을 적을 때는 지급 조건을 함께 적습니다. |
| 본인부담 | 필수 | 없으면 `없음`, 모르면 비워 둡니다(화면에 "원문 확인 필요"). |
| 신청방법 | 선택 | 온라인·방문 등 |
| 원문링크 | 필수 | 주관기관 공고 페이지 주소. 없으면 상세 페이지가 검색에서 제외(noindex)됩니다. |
| 주관기관 | 선택 | |
| 출처 | 필수 | `직접 입력` (온통청년 자동 수집분은 빌드가 채웁니다) |
| 마지막확인일 | 필수 | `2026-03-15` 형식 |
| 요약 | 선택 | "누구에게, 무엇을" 한 줄. 비우면 대상·혜택으로 자동 생성 |
| 포스터문구 | 선택 | 카드 포스터에 크게 들어갈 짧은 문구(예: `나의 첫 집, 여기 어때?`). 비우면 제목 사용 |
| 아이콘 | 선택 | 카드에 쓸 이모지 1개. 비우면 카테고리 기본 아이콘 |
| 무료 | 선택 | 참가비·본인 부담이 없을 때 `Y` (원문에 있을 때만) |
| 비고 | 선택 | 운영자 메모. 화면에는 "원문 확인 필요" 안내와 함께 작게 표시됩니다. |

비어 있는 필수 항목은 화면에 **원문 확인 필요**로 표시됩니다. 추정값을 넣지 않습니다.

## commentary.csv — 커먼빌리지 해설

| 열 | 적는 법 |
|---|---|
| slug | 공고의 slug |
| 해설 | 헷갈리는 조건, 놓치기 쉬운 점 2~4줄. 줄바꿈은 그대로 넣으면 됩니다. 원문에 없는 조건은 쓰지 않습니다. |
| 상태 | `초안` 또는 `승인`. **승인만 게시**됩니다. 초안은 공개되지 않습니다. |
| 작성일 | `2026-03-15` 형식 |
| 검수자 | 확인한 사람 |

해설이 `승인` 상태이고 원문링크가 있는 공고만 검색엔진에 색인됩니다. 나머지 공고는 목록에는 보이지만 상세 페이지에 noindex가 붙습니다.
