# 2026-10-01 리뉴얼 안내

공고 탐색 → 조건 확인 → 질문 초안 → 나의 활동 중심으로 화면을 재구성했습니다.

- 메인: 검색, 활동 유형별 탐색, 모집 공고 및 종료 공고 대체 표시
- 목록: 검색·지역·활동·기간 필터, 모집일/마감일 정렬
- 상세: 지원 내용, 확인이 필요한 비용/일정, 신청 요건, 질문 초안
- 나의 활동: 공고 저장/해제, 질문 초안/삭제
- 알림: 이메일 수집 없이 관심 조건만 브라우저에 저장
- 질문과 답변: `questions.html`, 동작: `assets/renewal.js`

## 운영 범위

**현재도 예시 데이터로 동작하는 정적 프로토타입입니다.** 실제 모집 공고, 로그인,
공유 Q&A 데이터베이스, 기관 답변, 이메일/카카오 발송은 연결되지 않았습니다.
질문과 관심 조건은 현재 브라우저에만 저장됩니다. 예시 공고의 신청 버튼은 비활성화했습니다.
이용자의 실제 신청 완료를 추정하거나 가상의 후기/대화를 생성하지 않습니다.

# 커먼빌리지 웹사이트

**전국 지자체의 한달살기·워케이션·살아보기 지원사업 공고를 모아 놓고,
여섯 가지 질문에 답하면 "내가 신청할 수 있는지"를 알려주는 웹사이트입니다.**

지금은 **시안(프로토타입)** 단계입니다. 실제로 돌아가는 화면이지만, 안에 들어 있는 공고와 지역 정보는
화면을 확인하려고 만들어 넣은 **가짜 예시**입니다. 진짜 서비스로 열기 전에 실제 정보로 바꿔야 합니다.

---

## 1. 사이트를 보려면

**`사이트 열어보기.bat` 파일을 두 번 클릭하세요.** 검은 창이 하나 뜨고, 브라우저에 사이트가 열립니다.

- 다 보셨으면 **검은 창을 닫으면** 사이트도 꺼집니다.
- "파이썬이 설치되어 있지 않습니다"라고 나오면 창에 적힌 주소에서 파이썬을 설치한 뒤 다시 두 번 클릭하세요.
  설치할 때 **"Add Python to PATH"** 항목에 꼭 체크해야 합니다.

---

## 2. 이 폴더에 뭐가 들어 있나

### 화면 파일 (11개)

파일 이름이 영어라서 헷갈립니다. **어느 파일이 어느 화면인지** 표로 정리했습니다.

| 파일 이름 | 어떤 화면인가 |
|---|---|
| `index.html` | **첫 화면(홈)** |
| `purpose.html` | 어떻게 지낼 계획인지 고르는 화면 |
| `diagnose.html` | 여섯 가지 질문에 답하는 화면 |
| `result.html` | 나에게 맞는 지역 3곳을 보여주는 화면 |
| `region.html` | 지역 한 곳을 자세히 보는 화면 |
| `programs.html` | 공고를 쭉 늘어놓은 목록 화면 (지난 모집 탭 포함) |
| `program.html` | 공고 하나를 자세히 보는 화면 (신청 가능 여부 판정) |
| `alert.html` | 알림 신청 화면 |
| `interest.html` | 관심 표시한 공고를 모아 보는 화면 |
| `for-gov.html` | **지자체 담당자용 소개 화면** |
| `report.html` | 지자체에 보내는 성과 리포트 (샘플) |

### 그 밖의 것

| 이름 | 무엇인가 |
|---|---|
| `assets` 폴더 | 사이트가 돌아가는 데 필요한 부품들. **함부로 건드리지 마세요** |
| `docs` 폴더 | 설명서. 아래 3번 참고 |
| `사이트 열어보기.bat` | 사이트를 켜는 파일 |
| `serve.py` | 사이트를 켜는 데 쓰이는 프로그램. 건드릴 일 없습니다 |

## 4. 어디까지 직접 해도 되나

### 직접 고쳐도 되는 것

- 공고 추가·수정·삭제
- 지역 정보와 6가지 점수
- 화면에 나오는 문구
- 카카오톡 채널 주소

**전부 `assets` 폴더 안의 `data.js` 파일 하나에서 고칩니다.**
어떻게 고치는지는 [2번 문서](docs/2_직접-고칠-수-있는-것.md)에 복사해서 쓸 수 있는 예시와 함께 적어 두었습니다.

> 고치기 전에 **파일을 복사해서 백업**해 두세요. 잘못 고치면 화면이 안 나올 수 있습니다.
> 그럴 때는 백업해 둔 파일로 되돌리면 됩니다.

### 개발자가 필요한 것

- 알림 메일을 실제로 발송하는 기능 (지금은 신청만 받고 메일이 나가지 않습니다)
- 검색(네이버·구글)에 잘 걸리게 만드는 작업
- 신청·문의 내용을 서버에 저장하는 기능

자세한 내용과 우선순위는 [5번 문서](docs/5_개발자에게-넘길-것.md)에 있습니다.
