# 커먼빌리지 웹 프로토타입

> 체류지원사업 공고를 구조화해 모아 놓고, 방문자가 1분 만에 "내가 신청 가능한가"를 판정받는 정보 목적지.

전국 지자체의 한달살기·워케이션·살아보기 지원사업 공고를 한곳에 모으고,
여섯 가지 질문에 답하면 공고마다 **신청 가능 / 확인 필요 / 대상 아님**을 근거와 함께 판정해 주는 웹앱의 프로토타입입니다.

빌드 도구도 프레임워크도 없습니다. HTML + CSS + 바닐라 JS 뿐이라 클론하면 바로 돕니다.

- 기획 근거: `CommonVillage_웹앱기획서_v2.0` (2026.09.01) · `CommonVillage_리텐션훅_추가본_v1.0` (2026.09.03)
- 제작: (주)이음전략소

> [!IMPORTANT]
> **여기 들어 있는 공고와 지역 지표는 전부 화면 검증용 예시입니다. 실제 모집 정보가 아닙니다.**
> 모든 페이지 상단에 그 사실을 알리는 고지 바가 있습니다. 운영에 올리기 전에 실데이터로 교체하고 고지 바를 제거해야 합니다.

---

## 빠른 시작

```bash
python serve.py
```

브라우저에서 `http://127.0.0.1:4399` 를 엽니다.

파일을 직접 더블클릭해도 대부분 동작하지만, `file://` 환경에서는 브라우저에 따라 스크립트가 막힐 수 있어 서버 실행을 권합니다.
파이썬이 없다면 `npx serve` 같은 어떤 정적 서버를 써도 됩니다.

## 코드로 강제한 원칙

기획서에서 "지키기로 한 것"을 문서가 아니라 코드에 박아 두었습니다. 고칠 때 이 원칙이 깨지지 않는지 확인해 주세요.

- **판정은 세 가지로만 말한다.** 규칙 하나라도 불충족이면 `대상 아님`, 불충족은 없는데 미상이 있으면 `확인 필요`, 전부 충족이어야 `신청 가능`. 애매할 때 '가능'으로 올리지 않습니다.
- **매칭은 규칙 기반.** 지역 적합도 60 + 사업 매칭도 40. 지표가 없으면 가중치에서 빼고 재정규화한 뒤 화면에 "데이터 없음"을 씁니다.
- **홈 지표 스트립에 임의 숫자가 없다.** 등재 건수·지역 수·최신 확인일을 데이터에서 계산합니다.
- **유료 노출은 상단 2건 + `지자체 협력` 라벨.** 라벨 없이 유료 배치하는 경로가 코드에 없습니다.
- **확인일이 14일을 넘기면** 카드와 상세에 경고 배지가 자동으로 붙습니다.
- **회원 시스템 없음.** 익명 ID(쿠키 2년) 하나로 `StayProfile → MatchResult → Interest`를 잇습니다.
- **경쟁률은 확보된 공고에만.** `pastResult`가 없으면 행 자체를 그리지 않습니다. 추정치를 만들지 않습니다.
- **G-99 첫 지표는 '적합 수요자 수'.** 노출 수는 참고 지표로 아래에 둡니다. 5명 미만 세그먼트는 숫자를 감춥니다.
- **화면에 'AI'라는 말을 쓰지 않는다.** 금지어(혁신적·최초·AI 맞춤형)도 쓰지 않습니다.
- 접근성: 본문 16px, 터치 타깃 44px 이상, 상태는 색+텍스트+아이콘 병행, 360px에서 가로 스크롤 없음.

## 지금 못 하는 것

1. **서버 렌더링이 아닙니다.** 공고·지역 목록을 클라이언트에서 그립니다. 검색이 제1 유입 채널이므로 실제 구축에서는 SSR이 필요합니다.
2. **백엔드가 없습니다.** 알림 신청·문의·구독·오류 신고·이벤트 로그가 전부 브라우저 `localStorage`에만 쌓이고 어디로도 전송되지 않습니다.
3. **맞춤 알림의 발송 인프라가 없습니다.** 프런트는 조건과 이메일을 받는 데까지입니다.

우선순위는 [docs/roadmap.md](docs/roadmap.md)에 정리해 두었습니다.
