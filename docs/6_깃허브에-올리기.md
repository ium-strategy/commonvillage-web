# 6. 깃허브(GitHub)에 올리기

## 깃허브가 뭔가요

**파일을 보관하고, 누가 언제 뭘 고쳤는지 기록이 남는 인터넷 창고**라고 생각하시면 됩니다.

- 실수로 잘못 고쳐도 **예전 상태로 되돌릴 수 있습니다**
- 담당자가 바뀌어도 파일과 기록이 그대로 넘어갑니다
- 개발자에게 "여기 있습니다" 하고 주소 하나만 주면 됩니다

이 폴더는 이미 창고에 넣을 준비가 끝나 있습니다. **인터넷에 올리는 것만 남았습니다.**

---

> ## ⚠ 먼저 읽어 주세요
>
> 저장소를 만들 때 **반드시 "Private"(비공개)을 선택하세요.**
>
> 설명서 안에 수익 구조, 지자체 영업 방식, 아직 정하지 못한 사항이 적혀 있습니다.
> 또 지금 들어 있는 공고와 실적은 예시라, 공개되면 **실제 모집으로 오해받을 수 있습니다.**

## 처음 한 번만 — 준비

### ① 깃허브 계정 만들기

<https://github.com> 에서 가입하세요. 무료입니다.

### ② 깃허브 데스크톱 설치 (권장)

개발자가 아니라면 **GitHub Desktop**을 쓰시길 권합니다. 명령어를 몰라도 클릭으로 됩니다.

<https://desktop.github.com> 에서 내려받아 설치하고, 만든 계정으로 로그인하세요.

---

## GitHub Desktop으로 올리기 (쉬운 방법)

1. GitHub Desktop을 엽니다
2. 왼쪽 위 **File → Add local repository** 를 누릅니다
3. **`C:\Users\catch\Documents\commonvillage-web`** 폴더를 선택합니다
4. 화면에 이 폴더가 나타나면, 오른쪽 위 **Publish repository** 버튼을 누릅니다
5. **"Keep this code private" 체크박스에 반드시 체크**하고 **Publish** 를 누릅니다

끝입니다. 이제 깃허브에 올라갔습니다.

### 이후에 파일을 고쳤을 때

1. GitHub Desktop을 열면 **고친 파일이 목록에 뜹니다**
2. 왼쪽 아래 칸에 **무엇을 고쳤는지 한 줄로** 적습니다 (예: `강릉 공고 마감일 수정`)
3. **Commit to main** 버튼을 누릅니다
4. 위쪽 **Push origin** 버튼을 누릅니다

이 네 단계를 파일 고칠 때마다 반복하면 기록이 쌓입니다.

> **한 줄 설명을 성의 있게 적어 두세요.** 나중에 "언제 뭘 바꿨더라" 찾을 때 이게 전부입니다.
> `수정` 이라고만 적으면 아무 도움이 안 됩니다.

## 명령어로 올리기 (개발자용)

터미널을 쓰실 줄 안다면 이쪽이 빠릅니다.

<https://github.com/new> 에서 빈 저장소를 만듭니다.
이름은 `commonvillage-web`, **Private 선택**, **README·.gitignore·license는 추가하지 마세요** (이미 있어서 충돌합니다).

그다음 이 폴더에서:

```bash
git remote add origin https://github.com/<계정이름>/commonvillage-web.git
git push -u origin main
```

이후 수정할 때는:

```bash
git add .
git commit -m "무엇을 고쳤는지 한 줄"
git push
```

## 팀에게 링크로 보여주고 싶다면

이 사이트는 인터넷 주소로 바로 열 수 있게 만들 수 있습니다 (GitHub Pages 기능).

저장소 → **Settings → Pages** → Source를 `Deploy from a branch`, 브랜치를 `main` / `(root)` 로 두고 저장하면
1~2분 뒤 `https://계정이름.github.io/commonvillage-web/` 에서 열립니다.

**다만 두 가지를 아셔야 합니다.**

- **비공개 저장소는 이 기능이 유료입니다.** 무료 계정에서 쓰려면 저장소를 공개로 바꿔야 하는데,
  그러면 위에 적은 대로 기획 내용이 인터넷에 그대로 공개됩니다.
  팀 공유가 목적이라면 **비공개로 두고 각자 폴더를 내려받아 `사이트 열어보기.bat`으로 보는 편이 안전합니다.**
- 링크로 공개한다면 **예시 데이터 안내(검은 띠)를 절대 지우지 마세요.**

## 자주 겪는 문제

**"파일을 못 찾겠어요"**
→ 폴더 위치는 `C:\Users\catch\Documents\commonvillage-web` 입니다.

**"Publish 버튼이 안 보여요"**
→ 이미 올라간 상태입니다. 대신 `Push origin` 버튼이 있는지 보세요.

**"비밀번호를 물어봐요"**
→ 명령어 방식에서 생기는 일입니다. 깃허브 계정 비밀번호가 아니라 별도의 토큰이 필요합니다.
GitHub Desktop을 쓰면 이 문제가 없습니다.

**"실수로 공개(Public)로 만들었어요"**
→ 저장소 → Settings → 맨 아래 **Danger Zone → Change visibility** 에서 비공개로 바꿀 수 있습니다.
빨리 바꾸시고, 이미 누가 봤을 가능성은 감안하세요.
