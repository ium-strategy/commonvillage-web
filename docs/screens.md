'지난 모집'은 별도 화면이 아니라 C-05의 탭입니다.

## C-00 홈

블록 순서는 기획서 §5.1의 5블록을 유지했습니다.

1. **히어로** — 확정 카피 "여행 말고, 한번 살아보세요." / "내게 맞는 지역 찾기 · 1분" / "회원가입 없이 결과까지"
2. **목적 카드 3** — 상황 기반 카피. 카드를 누르면 목적이 선택된 채로 진단 2단계부터 시작합니다
3. **모집 중 공고 6** — 마감임박순. 위에 시즌 안내 바, 아래에 알림 블록
4. **신뢰 근거 6카드** — 원문·확인일 정책, 판정 3상태, 유료 노출 라벨, 지표 출처, 비로그인, 오류 정정
5. **B2G CTA** — G-10으로 연결

지표 스트립(등재 공고 / 모집 중 / 등재 지역 / 최신 확인일)은 `data.js`에서 실제로 세어 표시합니다.
기획서 §5.1의 "실제 등재 수만 표기" 규칙 때문에 하드코딩된 숫자를 두지 않았습니다.

시즌 안내 바의 CTA는 알림 페이지가 아니라 **진단**으로 갑니다(리텐션 훅 §2.2-3).
조건을 먼저 받아야 맞춤 알림을 보낼 수 있기 때문입니다.

## C-02 진단 6단계

목적 / 기간 / 동행 / 차량·이동 / 우선조건 2개(목적별 분기) / 기초자격(연령대 + 거주 시·도).
한 화면에 질문 하나. 희망 시기·예산 문항은 M0 결정대로 넣지 않았습니다.

- 우선조건은 목적에 따라 보기가 달라집니다(`PRIORITY_SETS`). 정확히 2개를 골라야 넘어갑니다.
- 마지막 단계에 개인정보 수집 고지가 붙습니다 — 무엇을 왜 받는지, 지자체에는 어떤 형태로 가는지.
- 완료 시 `StayProfile`을 저장하고 매칭을 돌린 뒤 결과로 보냅니다. 로그인은 없습니다.
- 이 화면에는 알림 블록을 넣지 않았습니다. 진행을 끊습니다.

## C-03 추천 결과

지역 카드에 적합도 점수, 추천 이유 2줄, 주의점 1줄, **"신청 가능 판정 n건" 배지**, 6지표 막대가 들어갑니다.
배지가 클릭 동인이라 가장 눈에 띄게 두었습니다.

아래에 판정별 공고 목록(신청 가능 / 확인 필요)이 이어지고, 맨 아래가 **알림 수집 제1 지점**입니다.
여기 카피에는 실제 신청 가능 건수가 들어갑니다 — "지금은 신청 가능한 사업이 2건이에요."

## C-05 공고 목록 + 지난 모집

- 카드 규격: `[D-n] 사업명 / 혜택 요약 한 줄 / 지역·대상 요건 / 발주기관·확인일 / "내 조건으로 확인 →"`
- 정렬 기본값은 마감임박순, 신규 등록순으로 바꿀 수 있습니다
- 상단에 시즌 캘린더 스트립(앞으로 6개월 마감 예정 건수, 시즌 달 표시)
- **유료 노출 슬롯**: 목록 상단 '추천 공고' 최대 2건. 일반 카드와 같은 규격에 `지자체 협력` 라벨만 추가
- 목록이 5건 이상이면 3번째 카드 뒤에 알림 블록이 한 번 끼어듭니다
- `?tab=past` 는 종료 공고 아카이브. 카드마다 "다시 열리면 알림 받기" 버튼이 붙습니다

## C-06 공고 상세

왼쪽에 판정, 오른쪽에 사실 정보를 놓았습니다.

- **자격 판정 블록** — 3상태 배지 + 규칙별 근거 한 줄씩 + 판정 기준일 + "최종 자격은 발주기관이 정합니다"
- 진단 전이면 판정 자리에 "1분이면 확인됩니다" 유도 블록이 대신 들어갑니다
- 공고 요약(사용자 언어) + "요약과 원문이 다르면 원문이 맞습니다" 고지
- 공고가 요구하는 조건 목록 + **준비하실 서류**(자격 요건과 분리 — [rules.md](rules.md) 참고)
- 면책 문구 + **판정 오류 신고** 창구
- '한눈에' 표: 모집 기간·체류 기간·혜택·발주기관·지역·**지난 모집 실적**·확인일
- 원문 신청 / 관심 표시 / 알림 버튼

## G-10 지자체 전용

상품소개서 P2~P9 구조를 그대로 이식했습니다.
담당자 고충 3카드 → 왜 지금인가 → 하는 일 4단계 → 기존 방식 비교표 → 성과 리포트 샘플 → 수행 역량 → 도입 문의 → **모집 현황 리포트 구독 폼**.

> **수행 역량 블록은 비어 있습니다.** "[작성 필요]"로 두었습니다.
> 확인되지 않은 실적을 넣지 않는다는 기획서 원칙 때문에 임의로 채우지 않았습니다. 실제 실적으로 교체해야 합니다.

## G-99 성과 리포트

로그인 없는 비공개 URL 1페이지. `noindex, nofollow`.

- 첫 지표는 **적합 수요자 수**. 노출 수는 "참고 지표 — 성과 판단의 기준으로 쓰지 않습니다"라고 적어 아래에 둡니다
- 전환 깔때기 7단계: 노출 → 상세 조회 → 자격 판정 → 적합 판정 → 관심·알림 → 참여의향 → 원문 신청
- 지원자 분포는 **5명 미만 세그먼트의 숫자를 감춥니다**(재식별 방지)
- 탈락 사유 분포 + 다음 회차 설계 제안
- 기금 성과평가에 그대로 옮겨 쓸 수 있는 문장 블록
- '보고서 내려받기(PDF)'는 브라우저 인쇄로 처리했습니다. 인쇄용 CSS가 헤더·푸터·버튼을 숨깁니다
